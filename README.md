# Firebase-Auth
This application was an introduction to online databases. This application allows the user to create a user and login. The created user details gets uploaded to firebase and is stored online. The user has to enter their email address and a password. Once registered, the user will be redirected to the login page where they will have to re-enter their login credentials and click the login button. Below the login button is text asking if the user is new, and if they are, they can click it to navigate to the register page. Once the  user has logged in, the will be taken to a page with a gradient background. When creating a user, if the email address is not correctly formatted, the user will be informed. When logging in, if either username and password is wrong, the user will be informed. Once the user is added, their username can be seen in firebase, but there password is encrypted. The password can be reset through the firebase console via the user's email address.
